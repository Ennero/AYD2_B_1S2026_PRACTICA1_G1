## Seguridad

- Todas las contraseñas están hasheadas con **bcrypt** (10 rounds)
- Los hash de contraseñas tienen 60 caracteres aprox.
- La columna password en la DB acepta hasta 255 caracteres

## Integridad de Datos

- No hay invitaciones para propiedades vendidas
- Las fechas updated_at son posteriores a created_at
- Las fechas expected_date son realistas (futuras para aceptadas)
- Los agentes solo tienen propiedades creadas después de su registro
- Los clientes solo tienen registros después de su fecha de creación
- Todas las relaciones foreign key son válidas
